Онлайн-компиляторы (без установки ПО)
1.  [CodeUtility C++ Online (на русском)](https://cpp.codeutility.io/ru/)** — Простой и быстрый компилятор с русскоязычным интерфейсом.
2.  [OnlineGDB](https://www.onlinegdb.com/online_c++_compiler)** — Популярный компилятор со встроенным отладчиком (debugger) для пошагового анализа кода.
3.  [Replit (C++ Workspace)](https://replit.com/languages/cpp)** — Полноценная облачная среда, поддерживающая проекты из нескольких файлов.
4.  [Compiler Explorer (Godbolt)](https://godbolt.org/)** — Профессиональный инструмент для анализа кода и работы с разными версиями компиляторов.
5.  [JDoodle (C++ Online Terminal)](https://www.jdoodle.com/online-compiler-c++)** — Максимально легкий и быстрый инструмент для проверки коротких фрагментов кода.

План на изучение
1. Синтаксис и базовые конструкции
Первая программа и структура: Функция main, подключение библиотек (#include <iostream>), точка входа и выхода.
Переменные и типы данных: Базовые типы (int, float, double, char, bool), модификаторы (const).
Ввод и вывод данных: Использование std::cin и std::cout.
Операторы: Арифметические, логические и операторы сравнения.
2. Условные конструкции и ветвления
Конструкции выбора: if, else if, else.
Переключатель: switch / case для проверки множественных вариантов.
3. Циклы (повторение кода)
Цикл с параметром: for (классический и range-based для прохода по коллекциям).
Циклы с условием: while и do-while.
Управление циклами: Ключевые слова break (выход) и continue (пропуск итерации).
4. Функции
Объявление и определение: Сигнатура функции, передача аргументов по значению.
Возвращаемые значения: Использование return и типа void.
Области видимости: Локальные и глобальные переменные.
5. Базовые структуры данных
Массивы: Одномерные и многомерные статические массивы (type name[size]).
Строки: Работа со стандартным типом std::string и базовыми методами.
6. Указатели и ссылки (важнейший этап C++)
Указатели: Что это такое, взятие адреса (&), разыменование (*).
Ссылки: Отличие ссылок от указателей.
Передача аргументов: Передача по значению против передачи по указателю и ссылке.
7. Основы ООП (Объектно-ориентированное программирование)
Классы и объекты: Поля, методы, создание экземпляров.
Конструкторы и деструкторы: Инициализация и очистка объектов.
Инкапсуляция: Модификаторы доступа (public, private, protected).
